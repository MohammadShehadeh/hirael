## Findings considered and rejected (so they aren't re-audited)

- **"4 shipped block categories are undiscoverable on /blocks"** (direction
  DIR-02) — **FALSE.** The live `/blocks` index renders the complete 22-entry
  `CATEGORY_REGISTRY` via `BlockShowcase`; the 18-entry gap exists only in dead
  code, which Plan 005 removes.
- **`target="_blank"` reverse-tabnabbing in portfolio** — non-issue; `RingLink`
  auto-applies `rel="noreferrer"` (`templates/portfolio/primitives.tsx:92`).
  Confirmed by three independent audit passes.
- **chart.tsx `<style>` CSS sink** (security) — byte-identical to upstream shadcn
  and only reachable on consumer misuse (developer-authored config). Document as an
  upstream-parity note rather than diverging; not worth a code change.
- **Security response headers in `vercel.json`** (SEC-01) — real gap but
  deliberately deferred by the maintainer for this pass (static site, no auth/
  cookies/runtime input → small blast radius). Revisit if the `/embed/*` surface or
  threat model changes; write a `headers` block with `nosniff` + `Referrer-Policy` +
  HSTS and a report-only CSP scoped around the inline theme/embed scripts.
- **Portfolio `gsap` + `motion` coexistence** — not worth the ScrollTrigger rewrite;
  the template is intentionally the heaviest. (Plan 007 still swaps its
  `framer-motion` → `motion`; `gsap` stays.)
- **TypeScript 6 → 7 upgrade** — dev-only dep, no security/EOL cost; risks the
  React Compiler babel plugin + `eslint-config-next` toolchain. Revisit only when
  the native TS compiler's speedup justifies a deliberate toolchain pass.
- **Splitting `registry-meta.ts` (2855 lines)** — it's append-only, fully typed
  data with compile-time checking, not a tangled god object. Not worth the risk to
  the `build-registry.mjs` transpile-and-import step now.
- **CI micro-tweaks** (double `check:registry`, `vercel deploy | tail -n1`) — the
  redundancy is a deliberate fail-fast; the URL capture is Vercel's documented
  pattern. Not worth doing.
- **Doc catalog counts** — verified **accurate** (75 `registry:ui`, 70
  `registry:block`); no drift finding. (The file-map _labels_ are still wrong — that
  is Plan 008.)
- **mention-input BUG-04 / block-kind label casing (TD-04) / category-page shell
  duplication (TD-09) / DIR-06 llms.txt** — either folded into a selected plan
  (BUG-04 → Plan 003) or judged low enough value to defer; recorded so they're not
  re-surfaced as novel.
