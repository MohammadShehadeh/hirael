Hirael fills the gaps in shadcn/ui: the multi-selects, date pickers, dropzones and data tables you end up building on every project. Plus ready-made page sections and full templates built from them.

You install them with the shadcn CLI. The source lands in your project, so there is no package to update and nothing you can't change.

## Getting started

If your project already uses shadcn/ui, this is all it takes:

```bash
npx shadcn@latest add @hirael/multi-select
```

- **[Components](/components)** are the controls shadcn/ui leaves out, from inputs and pickers to data tables and editors.
- **[Blocks](/blocks)** are page sections: heroes, pricing, FAQs, auth screens, dashboards and app shells. One file each.
- **[Templates](/templates)** are complete landing pages, portfolios and SaaS sites, ready to edit.
- **[Utilities](/utilities)** are the hooks and helpers the components share, available on their own.

## How it works

- **You own the code.** The CLI writes plain `.tsx` files and rewrites imports to match your aliases.
- **Radix UI or Base UI.** Every item comes in both. Pick yours in the [Registry Customizer](/docs/customizer) and the whole site follows.
- **Your theme, not ours.** Items only use shadcn/ui tokens, so they match your colors, radius and fonts out of the box.
- **Light, dark and right-to-left.** Every item works in both modes and in RTL languages. See [Theming and RTL](/docs/theming).
- **Written for the React Compiler.** Components leave memoization to the compiler, so turn it on in your project.
